# LogicPOS License Generator

Отдельная утилита для генерации файла лицензии `licence.lic` для LogicPOS.

## Описание

Это приложение Windows Forms позволяет создать файл лицензии с зашифрованными данными компании, который используется системой LogicPOS для активации.

## Требования

- .NET Framework 4.8
- Windows OS

## Использование

1. Запустите приложение `LicenseGenerator.exe`
2. Заполните поля формы:
   - **HardwareId** - Идентификатор оборудования (обязательно)
   - **Company** - Название компании (обязательно)
   - **NIF** - Налоговый номер
   - **Address** - Адрес компании
   - **Email** - Email компании
   - **Telephone** - Телефон
   - **Reseller** - Продавец (по умолчанию "LogicPulse")
3. Укажите путь для сохранения файла или используйте кнопку "Browse..."
4. Нажмите "Generate License File"

## Алгоритм шифрования

- **Метод**: TripleDES (3DES)
- **Режим**: ECB
- **Дополнение**: PKCS7
- **Хеширование ключа**: MD5
- **Формат вывода**: Base64

Используется тот же алгоритм, что и в LogicPOS (`CryptographyUtils`), обеспечивая полную совместимость.

## Формат файла

Сгенерированный файл `licence.lic` имеет формат INI:

```ini
[Licence]
HardwareId=<зашифрованное значение>
Company=<зашифрованное значение>
Nif=<зашифрованное значение>
Address=<зашифрованное значение>
Email=<зашифрованное значение>
Telephone=<зашифрованное значение>
Reseller=<зашифрованное значение>
```

## Размещение файла

После генерации файл `licence.lic` должен быть размещен в директории с приложением LogicPOS.
